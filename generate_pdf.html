1. Mathematical Foundations of PSR and DSR

1.1 Academic Context

The Probabilistic Sharpe Ratio (PSR) and Deflated Sharpe Ratio (DSR) were introduced by David H. Bailey and Marcos López de Prado (2012, 2014) to address two fundamental flaws in traditional performance analysis: (1) non-normality of returns (skewness and kurtosis violating Gaussian assumptions), and (2) multiple testing selection bias (inflation of backtested performance as a function of trials tested).

1.2 Verification of CTO Critique: Annualized vs. Per-Trade Frequency Inconsistency

The CTO's critique regarding time-scaling double counting is mathematically correct.

Formal Proof of the Double-Counting Error:

Let r_t represent trade-level returns over N discrete observations. The empirical per-trade Sharpe ratio is defined as SR_trade = mean(r) / std(r). Let K = ATPY represent Average Trades Per Year. The standard annualization transform scales the point estimate by sqrt(K): SR_annual = SR_trade * sqrt(K).

The asymptotic normal test statistic Z in PSR (Bailey & López de Prado, 2012) is Z = (SR - SR*) * sqrt(N - 1) / sigma_SR. Under Gaussian returns, sigma_SR = sqrt(1 + 0.5 * SR^2).

If an engineer feeds the annualized Sharpe ratio SR_annual into the PSR formula while simultaneously setting sample size to total trade count N, the test statistic expands to:

Z_flawed = (SR_trade * sqrt(K) - SR*_annual) * sqrt(N - 1) / sqrt(1 + 0.5 * (SR_trade * sqrt(K))^2)

Because N represents total trades, total time in years is T_years = N / K. Substituting N = K * T_years shows that Z_flawed scales the numerator by an extra factor of sqrt(K) = sqrt(ATPY) compared to evaluating purely in annual or per-trade units.

Numerical Verification:

Evaluating the benchmark case (SR_trade = 0.10, N = 250 trades, K = 250 trades/yr):

  • Flawed Implementation (Annualized SR with Per-Trade N): Yields Z = 16.632, leading to PSR = 1.0000 (100% false statistical certainty).
  • Correct Per-Trade Implementation: Yields Z = 1.5740, leading to PSR = 0.9422 (94.22% confidence).

1.3 Correct Mathematical Formulation for DSR Calculation

To resolve dimensional inconsistency, all statistical inputs must be aligned to per-trade periodicity.

Step 1: Estimating Per-Trade Higher Moments

Skewness (gamma_1) = [ (1/N) * sum( (r - mean_r)^3 ) ] / sigma^3 Excess Kurtosis (gamma_2) = [ (1/N) * sum( (r - mean_r)^4 ) ] / sigma^4 - 3

Step 2: Per-Trade Probabilistic Sharpe Ratio (PSR)

PSR(SR*_trade) = Phi( [ (SR_trade - SR*_trade) * sqrt(N - 1) ] / sqrt( 1 - gamma_1*SR_trade + ((gamma_2)/4)*SR_trade^2 ) )

Step 3: Expected Maximum Sharpe Ratio E[max SR] Under Multiple Testing

When n_trials strategy variants are evaluated, Extreme Value Theory dictates the expected maximum Sharpe under the null hypothesis (H0: True SR = 0):

E[max SR] = mean(SR) + sigma_SR * [ (1 - gamma) * Z_inv(1 - 1/n_trials) + gamma * Z_inv(1 - 1/(n_trials * e)) ]

Where gamma ≈ 0.5772156649 (Euler-Mascheroni constant) and Z_inv is the inverse standard normal CDF.

Step 4: Correct sigma_SR Scaling

sigma_SR must be calculated as the empirical standard deviation of per-trade Sharpe ratios across all n_trials backtest variants:

sigma_SR = sqrt( (1 / (n_trials - 1)) * sum( (SR_trade_k - mean_SR_trade)^2 ) )

Step 5: Deflated Sharpe Ratio (DSR) Computation

SR*_ref = E[max SR] DSR = PSR(SR*_ref)

1.4 Strict Guardrails for n_trials

If n_trials = 1, EVT limits collapse. In strategy development, parameter tuning creates selection bias. Enforce:

  1. No Default Argument: The parameter signature must require an explicit integer (`n_trials: int`).
  2. Explicit Validation: Enforce n_trials >= 2. Throw `ValueError("n_trials must reflect total backtest iterations (N >= 2)")` if n_trials < 2.

2. Path-Dependent Drawdown Mechanics: Mark-to-Market vs. Closed-Trade

2.1 Failure of Closed-Trade Drawdown

Closed-trade drawdown samples equity strictly when trades are liquidated. Grid and martingale strategies avoid closing losing positions, holding open floating losses while realizing small gains.

[Closed-Trade Equity] [Mark-to-Market Real Equity] Equity Equity | / | / | / | /\ <-- Massive Floating Drawdown | / | / \ (60% Open-Equity Loss) | / | / \/\ |_____/ |_____/ \______ +------------------> Time +----------------------> Time (Hides catastrophic risk) (Captures true risk profile)

2.2 Mathematical Formulation of Continuous Mark-to-Market Drawdown

Mark-to-market equity E(t) sampled at interval dt includes unliquidated positions O(t):

E(t) = E_0 + Realized_PnL(t) + sum_{j in O(t)} Unrealized_PnL_j(t) Peak P(t) = max_{tau <= t} E(tau) MtM Drawdown DD_MtM(t) = (P(t) - E(t)) / P(t) Max MtM Drawdown MDD_MtM = max_{t in [0, T]} DD_MtM(t)

3. Fragility of Win Rate / Profit Factor & Alternative Metrics

3.1 Vulnerability of Profit Factor and Win Rate

Profit Factor (PF = (WR / (1 - WR)) * (Avg_Win / Avg_Loss)) can be engineered to arbitrarily high values by setting tight take-profits (+1%) and wide stop-losses (-50%). Under normal noise, WR reaches 98%, producing PF = 0.98 * (98/2) = 48.0. This masks severe left-tail blow-up risk.

[Symmetric / Right-Skewed Return] [Martingale Left-Skewed Return] Probability Probability | /\ | /\ | / \ | / \ | / \ | / \ | _________/______\________ | _______________________/______\ +------------------------------> Return +----------------------------------> Return (Bounded Left-Tail Losses) (Rare Catastrophic Blow-Up Loss)

3.2 Robust Quantitative Alternatives

  • Sortino Ratio: Replaces total variance with downside semi-variance below target return tau.
  • Calmar Ratio: Normalizes annualized return by maximum mark-to-market drawdown (Calmar = Return_annual / MDD_MtM).
  • Omega Ratio: Evaluates cumulative gains vs. cumulative losses across the continuous CDF.
  • Adjusted Sharpe Ratio: Penalizes raw Sharpe for negative skewness (gamma_1) and excess kurtosis (gamma_2):
    SR_adj = SR * [ 1 + (gamma_1 / 6)*SR - (gamma_2 / 24)*SR^2 ]

4. Frameworks for Measuring Backtest Overfitting

4.1 Combinatorially Symmetric Cross-Validation (CSCV) and PBO

CSCV (Bailey et al., 2014) partitions time-series returns into S equal blocks, forming C = Binomial(S, S/2) combinations of In-Sample (IS) and Out-of-Sample (OOS) splits.

C = S! / [ ((S/2)!)^2 ] PBO = (1 / C) * sum( Indicator( Relative_Rank_OOS < 0.5 ) )

A PBO > 0.50 indicates that in-sample optimization selected parameters no better than random chance out-of-sample.

4.2 Walk-Forward Validation

Timeline: [===== IS 1 =====][== OOS 1 ==] [===== IS 2 =====][== OOS 2 ==] [===== IS 3 =====][== OOS 3 ==]
Walk-Forward Efficiency (WFE) = Mean_OOS_Return_Annual / Mean_IS_Return_Annual

4.3 Purged and Embargoed Cross-Validation

To prevent data leakage caused by overlapping position holdings and autoregressive memory (López de Prado, 2018):

Training Block Purge Zone Test Block Embargo Zone Training Block [===========================] [ X X X ] [==========] [ E E E ] [===========================]
  • Purging: Removes training labels that overlap in time with active testing trades.
  • Embargoing: Removes training samples immediately following a testing block (e.g., 1-5% of samples).

5. Proposed Strategy Evaluation Architecture

5.1 Hard Knockout Gates (Non-Negotiable Fail States)

A strategy triggering any gate receives an immediate evaluation FAIL regardless of returns:

Hard Knockout Gate Mathematical Threshold / Condition Financial Justification
Mark-to-Market DD Ceiling MDD_MtM > 0.25 (25.0%) Eliminates strategies hiding open floating losses.
Deflated Sharpe Floor DSR < 0.05 (with explicit n_trials) Rejects strategies with < 5% probability of true skill.
Overfitting Threshold PBO > 0.50 (50.0%) Rejects setups where IS performance fails OOS.
Sample Power Gate N_trades < 100 trades Prevents small-sample noise from passing PSR bounds.
Martingale Asymmetry Gate WR > 0.80 AND (Avg_Loss / Avg_Win) > 3.0 Disqualifies high-win-rate strategies with tail-risk exposure.

5.2 Progressive Scoring Matrix (100-Point Rebalanced System)

Final Score = 0.35 * Score_Perf + 0.35 * Score_Rob + 0.15 * Score_Tail + 0.15 * Score_Exec
+---------------------------------------+ | Total Strategy Score (100%) | +---------------------------------------+ | +------------------+--------------+------------------+------------------+ | | | | +---------------+ +---------------+ +---------------+ +---------------+ | Performance | | Robustness | | Drawdown/Tail | | Execution | | (35%) | | (35%) | | Risk (15%) | | Risk (15%) | +---------------+ +---------------+ +---------------+ +---------------+ | - Sortino | | - Corrected DSR | | - MtM Max DD | | - Slippage | | - Calmar | | - WFE Score | | - Skewness | | Sensitivity | | - Adj Sharpe | | - Purged CV | | - Kurtosis | | - Friction | +---------------+ +---------------+ +---------------+ +---------------+
Payoff Asymmetry Penalty Multiplier (psi): If WR > 0.75 and (Avg_Loss / Avg_Win) > 2.0: psi = exp( -1.5 * ( (Avg_Loss / Avg_Win) - 2.0 ) ) Else: psi = 1.0 Subscore_Perf = Raw_Perf_Score * psi
